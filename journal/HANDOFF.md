# Passage Jeu (Sonnet) → Dev (Opus)

La conversation Jeu ajoute ici les bugs et blocages rencontrés (le plus récent en haut), puis
s'arrête. La conversation Dev les traite, coche la case, et note la correction (commit).

Format d'une entrée :

```
## AAAA-MM-JJ HH:MM — <titre court>
- Personnage / niveau / position (x,y,map) / job en cours :
- Commande lancée (exacte) :
- Attendu :
- Observé (message d'erreur exact, extraits courts de logs/*.log avec l'heure) :
- Reproductible ? :
- Etat laissé : (session ouverte/fermée, vivant/fantôme, jobs arrêtés)
- [ ] Traité par Dev :
```
