# Chaman

## Élémentaire (Ovale)
- Hors combat : arme Langue de feu si elle dure moins de 400 s.
1. Bouclier d'eau s'il expire dans moins de 2 s.
2. Plusieurs cibles (option) : Totem de magma si pas de totem de feu, sinon Nova de feu ; Orage sous 90 % de mana ; Chaîne d'éclairs.
3. Horion de flammes s'il manque ; Explosion de lave tant qu'Horion de flammes dure plus que son incantation.
4. Chaîne d'éclairs si l'Éclair est long à incanter et que l'Explosion de lave n'est pas prête avant la fin (option).
5. Éclair.

## Amélioration (Ovale)
- Hors combat : Furie-des-vents sur la main droite, Langue de feu sur la main gauche.
1. Plusieurs cibles : Totem de magma / Nova de feu ; Chaîne d'éclairs à 5 charges de Maelstrom.
2. Éclair à 5 charges de Maelstrom.
3. Horion de flammes s'il expire dans moins de 2 s ; Frappe-tempête si son débuff manque ; Bouclier de foudre s'il manque.
4. Totem de magma si pas de totem de feu ; Esprit farouche ; Rage du chaman ; Horion de terre ; Frappe-tempête ; Fouet de lave ; Nova de feu.
- Mana : Rage du chaman sous 25 % ; Orage sous 50 %.
- Recharges : Maîtrise élémentaire, Esprit farouche, Totem d'élémentaire de feu, Héroïsme/Furie sanguinaire.
